# Evaluation Foundation

Phase 1 evaluation is document-processing focused rather than answer-quality focused.

Track:

- number of PDFs attempted
- accepted/rejected count
- rejection reason distribution
- pages processed
- chunks produced
- duplicate count
- extraction warnings
- deterministic chunk output

Phase 2+ will add retrieval metrics such as Hit@K and MRR; later RAG phases will add groundedness and citation correctness.
